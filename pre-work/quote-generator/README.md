# Quote Generator

A small Python program that randomly displays one of ten quotes with its author.

## Requirements

- Python 3.10 or newer
- No third-party Python packages

## Setup (Windows PowerShell)

Open PowerShell in this folder, then create and activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

There are no external packages to install. To run the program:

```powershell
python main.py
```

Each run prints a randomly selected quote and author.
